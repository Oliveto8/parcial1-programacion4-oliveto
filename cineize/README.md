#  Cine & Candy Bar Web App

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.3.

## Sobre el Proyecto

Aplicación web de cine desarrollada en Angular con componentes standalone. Incluye la gestión visual y funcional de la cartelera de películas, próximos estrenos y una sección de **Candy Bar** integrada mediante una grilla uniforme, tarjetas personalizadas con control de imágenes (`object-fit: contain`) y diseño responsivo adaptado.

## Development server

ng serve
